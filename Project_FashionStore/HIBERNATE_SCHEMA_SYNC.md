## 🔄 Migration Strategy: Hibernate Self-Discovery

**Why this approach?**
- Java entities are the single source of truth
- Automatic schema updates on startup
- No manual SQL script maintenance
- Type consistency across Java ↔ Database

## 🔧 Troubleshooting

### Issue: "Unknown column" error
**Solution:** Delete database and let Hibernate recreate:
1. Drop all tables manually (see Step 3)
2. Restart application
3. Hibernate will auto-create all tables

### Issue: Column type mismatch
**Solution:** Check the entity annotation matches column definition
Example:
```java
@Column(name = "is_active")
private Boolean isActive;  // → BIT column
```

### Issue: Foreign key constraint error
**Solution:** Ensure parent table exists before child
Hibernate handles this automatically, but if manual insertion:
1. Insert Role before Account
2. Insert Account before Customer
3. Insert Product before ProductVariant
4. Insert ProductVariant before OrderItem

### Check Hibernte Logs
Add to application.properties:
```properties
spring.jpa.show-sql=true
spring.jpa.properties.hibernate.format_sql=true
spring.jpa.properties.hibernate.generate_statistics=true
logging.level.org.hibernate.SQL=DEBUG
logging.level.org.hibernate.type.descriptor.sql.BasicBinder=TRACE
```
